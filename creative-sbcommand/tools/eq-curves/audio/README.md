# EQ 原音 / 效果对比音频

生成日期：2026-11-12（UTC+8）。全部素材为固定种子合成诊断音频，无用户录音、真实游戏脚步或第三方音乐。

## 试听入口

打开上一级index.html，在播放器中切换原音A与EQ B；预设及耳机/扬声器模式对应原图册。播放器不会自动播放。

- [原音 A](wavs/original.wav)：16秒、48 kHz、双声道PCM16。
- [脚步增强 A→B](FootstepEnhancer-A-then-B.wav)：前4秒原音、0.25秒静音、后4秒EQ，使用同一段瞬态素材。
- [FPS耳机 A→B](FPS-A-then-B.wav)：同格式，使用低频片段。
- [音乐 A→B](Music-A-then-B.wav)：同格式，使用中频谐波片段。
- [平直校验 A→B](Flat-A-then-B.wav)：两段相同，供校验，不应人为听出差异。

## 16秒素材分段

- 0–4秒：低频脉冲与谐波。
- 4–8秒：中频谐波与共振峰形状（非人声录音）。
- 8–12秒：短促瞬态与摩擦噪声（非真实脚步录音）。
- 12–16秒：宽带噪声与高频层次。

## 比较口径

实际使用sbc-eq生成34预设×2输出模式；33种不同曲线/基线共用音频文件。所有版本统一附加-2.950048 dB（线性0.712028876），仅为了保留峰值余量，未逐预设归一化。A与所有B采用同一个增益，因此响度差仍属于EQ变化。

浏览器试听固定48 kHz、Q=1及上述公共衰减；图册的采样率/附加增益控件只改变曲线，不会实时重新生成试听音频。PCM16仅用于通用播放，Rust中间结果为float32，量化误差不超过1/32768。

68个预设/模式映射及每个文件的SHA256、峰值、量化误差见audio-manifest.json。相同曲线共用同一文件，Speaker/Headphone不同的预设保留不同文件。

复现：在creative-sbcommand目录运行 `./tools/audio-env/Scripts/python.exe -X utf8 ./tools/build-eq-audio.py`。本脚本不打开任何音频设备。
