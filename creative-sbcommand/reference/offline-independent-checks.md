# 离线 EQ 独立验收要点

2026-11-12：实现代理交付后，主对话独立复核以下实际输出，不把代码分支执行等同验收通过。

- 34个预设均可列出，原始Speaker/Headphone设置保持独立。
- 48 kHz单声道脉冲经FootstepEnhancer，与独立SciPy SOS参考比较实际导出波形。
- Flat对浮点音频不改增益；前级/余量dB映射与说明一致。
- 立体声单侧激励不泄漏到静音声道，输出帧数/声道/采样率保持。
- PCM16/24/32及float32输入可处理；输出float32有限且不静默截幅。
- FPS的Speaker全零、Headphone非零，应产生可测差异。
- 已有输出、相同路径、硬链接和符号链接均不能破坏源或既有文件。
- NaN/Inf、无效预设、无法支持的采样率/格式、巨大dB参数以非零状态失败，不留半成品。

源码初检发现应特别验证两处：滤波器状态必须按channels×bands分配；f64结果转f32后还要确认有限，不能只检查转换前的f64。

本文件是验收清单，不代表实现已通过。真实结果将在offline-progress.md和tools/offline-eq-results.md记录。
