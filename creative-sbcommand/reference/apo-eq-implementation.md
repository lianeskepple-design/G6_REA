# G6 APO 十段均衡器实现（静态证据）

> **2026-11-12 更正（优先于下文旧内容）**
>
> 后续用虚表与 RTTI 类名做的深入分析推翻了本文几处早期判断，详见[apo-effects-structure.md](apo-effects-structure.md)：
>
> - **拓扑不是 10 段全峰值**，而是 **1 低架 + 8 峰值 + 1 高架**（`CEqFilterLowFreq` / `CEqFilterPeak` / `CEqFilterHighFreq`，由 `CEqChan` 构造函数 `0x180090400` 分别钉在第 1 / 中间 8 / 第 10 段）。
> - **段步进是 `0x50`，不是 `0x338`**；`0x338` 是每声道 `CEqChan` 的大小。
> - **带宽比在段基址 `+0x40`，不是 `+0x14`**。其余（中心频率 `+0x38`、采样率 `+0x3c`、`f/fs` `+0x30/+0x34`、默认增益 `1.0f` `+0x28/+0x2c`）仍然成立。
> - 因此下文"每段带宽推 Q≈1.4142、全段统一 Q"的结论只适用于**中间 8 个峰值段**；两端是搁架滤波器，不适用该 Q 换算。
>
> 文中把 `0x180196550` 当作 8 项虚表也是误读：它是 `CEqChanLFE` 的 1 项 vftable，后面接了两个 RTTI COL 指针。


2026-11-12。目标：`C:\Windows\System32\KSUSBAPO64.dll`，1.2.109.0，SHA256 `f7c64954…037156`。PE x86_64、已剥离符号、MSVC 构建。分析工具：Craft Anything（native 工具集）。

## 已定位的函数

| 地址 | 作用 | 规模 |
|---|---|---|
| `sub_180090660` | 十段均衡器的构造函数 | 3 个基本块、73 条指令、调用 4 个子函数 |
| `sub_180090bd0` | 单个频段的滤波器描述符构建 | 由上面的构造函数在循环里逐段调用 |

构造函数的循环体：

```c
for (band = count; band != 0; band--) {
    sub_180090bd0(desc, &freq_table);   // desc 步进 0x338
}
```

`freq_table` 就是文件偏移 `0x193390` 那张表（VA `0x180196590`）：`31 62 125 250 500 1000 2000 4000 8000 16000`。

## 频段宽度由相邻频点推导

`sub_180090bd0` 读取表中**相邻两项**（`[rdi]` 与 `[rdi+4]`）并求比值：

```asm
movss xmm2, [rsi]     ; f[i+1]
movss xmm1, [rdi]     ; f[i]
divss xmm2, xmm1      ; ratio = f[i+1] / f[i]
```

循环跑 8 次，第 9 段用 `[r15+0x24]` 单独处理。也就是说**每个频段的带宽是从相邻中心频率比推出来的**，不是外部传入的固定 Q。

这对复刻有直接影响：真实带宽是由频率比算出来的，不是一个写死的 Q。实测这张表所有比值都接近 2.0（见下节）。

## 频段描述符的内存布局

从 `sub_180090bd0` 的写入顺序可以还原每段（步进 `0x338`）的前部结构：

| 偏移 | 内容 | 证据 |
|---|---|---|
| `+0x28` / `+0x2c` / `+0x40` | `1.0f`（默认增益倍数） | 常量 `0x3f800000` |
| `+0x30` / `+0x34` | `f / fs`（归一化频率） | `divss xmm0, xmm6` |
| `+0x38` | `f`（中心频率，Hz） | `movss [rcx+0x38], xmm1` |
| `+0x3c` | `fs`（采样率） | `movss [rcx+0x3c], xmm6` |
| `+0x14` | `f[i+1] / f[i]`（带宽比） | `divss xmm2, xmm1` |

`xmm6` 由构造函数里 `cvtsi2ss xmm6, [r14+0x10]` 得到，即整数采样率转浮点。

## 带宽：不是固定 Q（本节已修正）

实测相邻比值 `2.000, 2.016, 2.000 …` 基本恒定为一倍频程，我起初据此推出"全段 Q≈1.4142"，**这个结论是错的**，已被后续类名与指令级证据推翻。

准确的拓扑与公式见[apo-effects-structure.md](apo-effects-structure.md)：

| 段 | 类型 | 带宽参数 |
|---|---|---|
| 第 1 段（31 Hz） | 低架 | `tan(w0/2)` |
| 第 2–9 段 | 峰值 | `tan(w0/4)` |
| 第 10 段（16 kHz） | 高架 | `tan(w0/2)` |

也就是说 **10 段 = 1 低架 + 8 峰值 + 1 高架**，首末两段根本不是峰值滤波器，没有 Q 可言。

把中段 `alpha = tan(w0/4)` 换算成 RBJ 的等效 Q（`Q = sin(w0)/(2·tan(w0/4))`，48 kHz）：

| 段 | 频率 | 等效 Q | 等效带宽 |
|---|---|---|---|
| 2 | 62 Hz | 2.000 | 0.714 倍频程 |
| 4 | 250 Hz | 1.9996 | 0.714 |
| 6 | 1 kHz | 1.994 | 0.716 |
| 8 | 4 kHz | 1.899 | 0.751 |
| 9 | 8 kHz | 1.616 | 0.879 |

低频段等效 Q 接近 2.0；越靠高频因 `tan` 非线性，等效 Q 越低（8 kHz 处降到 1.62）。

修正方式不是"把 1.0 改成某个常数"——必须分别实现低架、峰值、高架三种二阶节，并按段选择公式。

### 实现状态（2026-11-13）

`app/src/eq_core.rs`（库目标 `aurora_audio_command`，CLI 与桌面共用）按本节实现滤波核心：

- 第 1 段 `BandKind::LowShelf`、第 2–9 段 `BandKind::Peaking`（`alpha = tan(w0/(2·ratio))`，ratio 取相邻频点比）、第 10 段 `BandKind::HighShelf`。
- 架式段由 `apo_eq::low_shelf_from_db` / `high_shelf_from_db`（`app/src/apo_eq.rs`）按 APO 系数端口
  （`0x180087970` / `0x1800887E0`）实现，调用点在 `app/src/eq_core.rs:351`、`app/src/eq_core.rs:354`；
  `Biquad::design` 里的 RBJ 斜率 `S = 1` 只保留为对照（`app/src/eq_core.rs:7`），不在渲染链上。
- 单元测试 13 项通过（另有桌面 6 项），其中：峰值段中心点达到标称增益且 DC/Nyquist 为单位增益、架式段在各自端点达到标称增益、带宽比非法（0 / NaN / 负数）被拒、单段整链响应命中标称增益、preamp/headroom 计入响应、34×2 条原厂曲线响应全程有限。
- `Chain::response_db` 同时驱动桌面 Equalizer 页的曲线图，因此界面显示的就是渲染使用的响应。
- 两套验证均通过：`verify-offline-eq.py` E2E PASS（31 Hz 级联实测 2.389 dB，与理论差 < 0.15 dB）；`verify-offline-eq-independent.py` 23/23（Rust 与 SciPy 独立实现最大样本差 < 1e-7）。

## 增益是线性倍数，不是 dB

`sub_180090bd0` 反复写入常量 `0x3f800000`（= 1.0f）到各频段的增益槽位：

```asm
*(uint32_t*)(rcx + 0x28) = 0x3f800000;
*(uint32_t*)(rcx + 0x2c) = 0x3f800000;
*(uint32_t*)(rcx + 0x40) = 0x3f800000;
```

默认值 1.0 对应 0 dB，说明内部存的是**线性增益倍数**。这一点与 USB 抓到的 `96 <id> <float32>` 通知一致（SmartVol 74 传的是 0.74 而不是 74）。

## 静态分析的边界

真正的双二阶系数运算走的是虚调用：

```asm
(**(uint64_t*)(rax + 0x18))();
```

目标函数由对象虚表在运行时决定，静态提升器无法跟进。所以：

- **已确认**：10 段结构、频点表、带宽由相邻频点比推导、增益为线性倍数。
- **未确认**：具体滤波器拓扑（peaking / shelving / 带通级联）、Q 的确切公式、是否级联多级。

要坐实这几点，需要跟进虚表目标函数，或改用运行时/实测手段。

## 对复刻版的建议

1. 保留 10 段频点 `31/62/125/250/500/1k/2k/4k/8k/16k`，但**不能只改一个 Q 常数**：需要 3 种二阶节——第 1 段低架、第 2–9 段峰值、第 10 段高架。
2. 峰值段 `alpha = tan(w0/4)`；首末架式段 `alpha = tan(w0/2)`。这比"等效 Q≈2.0"更准确，且自动带上高频非线性。
3. 增益内部用线性倍数，对外做 dB↔线性换算。
4. 改完必须用现有离线验证脚本重新核对曲线（`tools/verify-offline-eq.py` 与独立复核脚本），不要凭此声称"已还原原厂"——差分方程形式（DF1 / DF2T）仍未确认。
